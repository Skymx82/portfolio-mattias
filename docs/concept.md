# Concept

## Positionnement

Portfolio personnel de Mattias Mathevon, étudiant BTS SIO option SLAM (2e année), candidat au passage E6 fin mai 2026. Cofondateur Tolarys, fondateur AutoSoft.

Le portfolio sert deux audiences :

1. **Le jury E6** (profs + pros invités) : il doit pouvoir, en moins de 30 secondes, identifier les compétences C1 à C6 couvertes par chaque projet, accéder aux rapports PDF, et juger la maîtrise technique réelle.
2. **Lecteur secondaire** (pro qui découvre Mattias après le BTS) : il doit comprendre le profil entrepreneurial dès le Hero, voir le niveau front-end démontré par le site lui-même, et avoir envie de creuser.

## Angle distinctif

Trois affirmations que ce portfolio assume sans détour :

- **Production réelle, pas projets d'école seuls** : AutoSoft est en production avec 4 auto-écoles utilisatrices. Tolarys facture 5 clients. Cela ne se voit dans aucun autre portfolio BTS.
- **Maîtrise front-end de niveau studio** : le portfolio lui-même est la démonstration. GSAP, Lenis, R3F, scènes cinématiques, transitions shader. Aucun autre candidat BTS de la promo n'aura ce niveau d'exécution.
- **Rigueur scolaire intacte** : malgré l'ambition technique, la grille de lecture E6 est respectée. Compétences mappées, sections obligatoires (E5, Veille, Perspectives, Stages), rapports PDF disponibles.

## Ton éditorial

Trois mots directeurs : **narratif, sombre, précis**.

- **Narratif** : on raconte le parcours en scrollant. Chaque section a une fonction dramatique (présentation, conflit, résolution). Pas de catalogue plat.
- **Sombre** : palette charbon dominante, lumière par contraste. Aucune couleur pastel, aucun glassmorphism rose. Pas un look "site corporate optimiste".
- **Précis** : copie courte, pas de formules type "passionné par le code", pas d'adjectifs faibles. Chiffres concrets, dates exactes, mots techniques quand ils sont utiles.

## Promesses non tenues délibérément

Pour cadrer ce que ce portfolio **n'est pas** :

- Ce n'est pas un site Awwwards Site of the Day mondial. Cela demanderait un studio de 20 personnes et 6 mois.
- Ce n'est pas un portfolio bilingue. FR uniquement, jury français, candidature Awwwards post-E6 acceptée en FR.
- Ce n'est pas un manifeste de design system propre comme Linear. Le ton reste celui d'un dev solo de 18 ans, pas d'une entreprise B2B.

## Critères de succès post-E6

- Mention obtenue à l'E6 (cible Très Bien).
- Site déposé en candidature Awwwards Honorable Mention dans les 30 jours qui suivent l'E6.
- Lighthouse perf >= 85, accessibility >= 95, best-practices >= 95, SEO >= 95.
